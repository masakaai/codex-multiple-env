# Launch kit

## One-line description

Masaka keeps multiple ChatGPT account + workspace identities signed in and lets
the native Codex CLI select one without repeated logout/login.

## English announcement

Managing Personal, Business, and Enterprise identities in Codex should not mean
logging the others out. Masaka gives each account/workspace pair its own
`CODEX_HOME`, keeps the official Codex login flow, and adds a tiny manager for
profiles, 5-hour/weekly limits, token activity, and reset cards. Select with
`/use`, then run native `codex` as usual.

Repository: https://github.com/masakaai/codex-multiple-env
